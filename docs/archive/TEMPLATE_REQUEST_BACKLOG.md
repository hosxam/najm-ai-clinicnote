## Priority Guidance

High priority:

- Repeated by multiple doctors
- Common OPD workflow
- Improves safety or clarity
- Blocks adoption

Medium priority:

- Useful but not urgent
- Specialty-specific request with clear wording

Low priority:

- Rare workflow
- Nice-to-have output variation
- Needs more evidence

Rejected / unsafe:

- asks for diagnosis/treatment advice
- asks for real patient data processing
- contains patient identifiers
- asks for official/legal/certified determinations
