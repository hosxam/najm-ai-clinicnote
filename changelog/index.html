Public updates for Najm AI ClinicNote.

May 20, 2026 — Beta Release Candidate

  • 150 workflows across 15 specialties with chips, Autofill presets, and V4 Advanced data.
  • All 15 specialties now visible in the OPD specialty dropdown (was 7).
  • All 150 workflows have complete V4 Advanced coverage: history drafts, exam details, investigation options, and plan options.
  • Zero validator failures across all systems (27,396 PASS).
  • Beta release documentation created: release notes, tester guide, known limitations, and self-review checklist.
  • Known cosmetic: 3 golden output pattern warnings (pre-existing, non-blocking).

May 17, 2026

  • Autofill is now enabled by default for the v2 OPD workflow.
  • Doctors can review, untick, and adjust Autofill defaults before generating any note.
  • A visible Autofill toggle now turns default selections on or off without leaving the page.
  • Use ?speed=off to disable Autofill while keeping v2 workflow search and chips.
  • v1 fallback remains available with ?data=v1.
  • Doctor testing package and feedback review system prepared. Feedback forms are live.

May 16, 2026

  • SEO foundation pages, sitemap, robots.txt, canonical URLs, and metadata added.
  • Public trust, examples, feedback checklist, privacy, safety, changelog, and about content added.
  • OPD Speed Mode remains primary, v2 remains default, and v1 fallback remains available with ?data=v1.

May 13, 2026

  • Calculator expansion: 8 high-impact clinical scores added (HEART, CURB-65, Ottawa Knee/Ankle, Wells DVT/PE, GCS, McIsaac/Centor).
  • Public trust fixes: stale counts updated, homepage examples enriched.
  • Calculator workflow mapping and Advanced Mode integration.

  • Premium healthtech UI refresh.
  • Medical Report Draft added to the normal site.

May 10, 2026

  • v2 workflow search, visible chip groups, and inline custom entries stabilized.
