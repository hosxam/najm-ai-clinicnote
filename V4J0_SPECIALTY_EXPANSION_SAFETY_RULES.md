# V4J-0 Safety Rules for Specialty Expansion

## Date
2026-05-19

## Universal Rules (all specialties)

1. **No triage recommendations.** Documentation prompts describe what was assessed, not what action to take.
2. **No disposition advice.** Never suggest admit, discharge, observe, or transfer decisions.
3. **No "send to ER" wording.** ClinicNote does not route patients.
4. **No medication dosing.** Class-level documentation ("antibiotic plan documented") only.
5. **No procedure instructions.** "Procedure documented" not "how to perform."
6. **No treatment recommendations.** "Plan documented if clinician decided" not "should treat with."
7. **No guideline endorsement.** Source registry is for future review only.
8. **All red flags as documentation prompts only.** "Red flags assessed and documented" not "red flags require referral."
9. **Clinician review required** on every prompt, every option.
10. **Local protocol applies.** UAE/Dubai institutional policy supersedes any documentation prompt.
11. **All examples fictional/de-identified.** Never use real patient scenarios.

## Emergency / Urgent Care Specific Rules

| Allowed | Forbidden |
|---------|-----------|
| "documentation prompt" | "must admit" |
| "documented if assessed" | "urgent referral required" |
| "clinician-entered plan" | "give adrenaline" |
| "local protocol applies" | "start antibiotics" |
| "vital signs documented if measured" | "CT required" |
| "GCS documented if assessed" | "rule out MI" |
| "burn depth documented if assessed" | "sepsis pathway" |
| "wound type and closure documented" | "send to emergency department" |
| "chest pain character documented" | "admit for observation" |
| "cardiac risk factors documented" | "discharge with" |
| "red flags assessed and documented" | "activate trauma team" |

## Medication-related Emergency Prompts

Only if generic and clinician-confirmed:
- "Analgesia plan documented if decided by clinician."
- "Antibiotic plan documented if decided by clinician."
- "Tetanus prophylaxis documented if administered."

Never:
- Agent names, doses, frequencies, routes
- "Give adrenaline IM"
- "Start IV antibiotics"
- "Prescribe [drug name]"
