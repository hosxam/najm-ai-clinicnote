## Recommendation: Emergency / Urgent Care

**Priority score: 25** — highest across all dimensions.

### Why
1. Highest OPD usefulness — every ED/urgent care encounter involves documentation
2. Highest documentation repetition — templated notes across trauma, wound, burn, allergy, chest pain, SOB, abdominal pain, syncope, fever
3. Hospital credibility — fills clear gap for hospital-based clinicians
4. Calculator-ready — HEART, TIMI, GRACE, Wells, CURB-65, NEWS2, GCS all reference emergency/urgent care scenarios
5. SEO value — emergency documentation keywords have high search volume
6. Safety documented — all items would use "documented if assessed" phrasing, no triage advice, no treatment algorithms

### Safety Principles
- Documentation prompts only, no triage/treatment advice
- No disposition recommendations (admit/discharge/observe)
- No emergency management instructions
- No trauma activation criteria
- No NEWS2/MEWS implementation unless registry-verified
- All prompts: "documented if assessed"

## First 10 Workflows for Emergency / Urgent Care

1. **Minor trauma documentation** — wound, abrasion, contusion, sprain documentation
2. **Wound care / laceration** — wound type, closure, tetanus status documentation
3. **Burn assessment** — depth, TBSA, site documentation (no fluid formulas)
4. **Allergic reaction** — trigger, rash, angioedema, respiratory status documentation
5. **Head injury** — mechanism, GCS documentation, red flags documented if assessed
6. **Chest pain** — character, radiation, cardiac risk factor documentation (no HEART/TIMI scoring recommendation)
7. **Shortness of breath** — onset, triggers, O2 sats, respiratory exam documentation
8. **Abdominal pain** — location, character, surgical history, examination documentation
9. **Syncope** — prodrome, witness account, cardiac history documentation
10. **Fever / suspected infection** — source, vitals, hydration, sepsis red flags documented if assessed
